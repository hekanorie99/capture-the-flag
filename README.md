# Capture the flag

Офлайн-игра «Захват флага» для Android: 3D от первого лица, боты, все текстуры как «ошибка текстур».

## Файлы в репозитории (все лежат в корне)
- index.html — вся игра
- manifest.json — настройки приложения (название, полный экран, иконки)
- sw.js — работа без интернета
- icon-192.png, icon-512.png — иконка
- README.md — эта инструкция

## Как выложить с телефона
1. Открой github.com в Chrome, меню ⋮ → «Версия для ПК» (так проще).
2. Создай репозиторий: + → New repository → имя, например, capture-the-flag → Public → Create repository.
3. Текстовые файлы: Add file → Create new file → впиши имя (index.html) → вставь код → Commit changes. Повтори для manifest.json, sw.js, README.md.
4. Иконки: Add file → Upload files → выбери icon-192.png и icon-512.png → Commit changes.
5. Включи сайт: Settings → Pages → Source: Deploy from a branch → Branch: main, папка / (root) → Save.
6. Через 1–2 минуты вверху страницы Pages появится ссылка вида https://ИМЯ.github.io/capture-the-flag/ — это игра.

## Установка на Android
1. Открой ссылку в Chrome.
2. Меню ⋮ → «Установить приложение» (или «Добавить на главный экран»).
3. Запускай с иконки: игра откроется на весь экран. После первой загрузки интернет не нужен.

## Если обновляешь файлы
Замени файлы на GitHub, подожди 1–2 минуты. Удали старое приложение с экрана и установи заново, если не обновились иконка или название. В sw.js при крупных обновлениях меняй номер в CACHE (ctf3d-v4 → ctf3d-v5).

## Правила
- Матч = 3 раунда по 7 минут (всего 21 минута). Счёт копится между раундами.
- Побеждает команда, первой набравшая 3 захвата. Если время вышло, побеждает у кого захватов больше, иначе ничья.
- Захват: принеси вражеский флаг на свою базу.
- Погибшие возрождаются через 4 секунды. Здоровье медленно восстанавливается, если по тебе не стреляли.

## Управление
- Левая половина экрана: стик движения.
- Правая половина: свайп — поворот.
- ОГОНЬ: стрелять (удерживай). Кружок справа: смена оружия (нож, пистолет, автомат, граната).
- II в правом верхнем углу: пауза → c0ntinue / m3nu (выход из матча в меню).

## Меню
- g4me — начать матч. ex1t — выйти (браузер не может закрыть приложение сам: выйдет из полного экрана, дальше смахни приложение).
- История матчей хранится в памяти приложения (последние 50): результат, счёт, убийства/смерти, время.
